# 沪知实验室

面向上海高中学习场景的互动知识演示平台。可按高一、高二、高三和学科筛选，用参数控制、动态曲线、结构图与时间轴理解抽象知识。

![沪知实验室界面](docs/preview.png)

## 学科与演示

| 学科 | 演示 |
| --- | --- |
| 数学 | 函数变换、概率模拟 |
| 物理 | 抛体运动、波的叠加 |
| 化学 | 化学平衡、酸碱滴定 |
| 生物 | 遗传组合、酶的活性 |
| 语文 | 论证结构、诗词意象 |
| 英语 | 句法拆解、时态轴 |
| 历史 | 近代时间轴、工业革命 |
| 地理 | 正午太阳高度、热力环流 |
| 思想政治 | 供给与需求、国民经济循环 |

年级归属用于推荐和筛选，跨年级复习知识可同时出现在多个年级。内容依据普通高中课程知识组织，不是官方教材或考试说明。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与代码检查：

```bash
npm run lint
npm run build
npm run test:e2e
```

## 技术栈

React 19、TypeScript、Vite、Lucide Icons。所有知识图形均由浏览器原生 SVG 与 CSS 绘制，无后端依赖。
